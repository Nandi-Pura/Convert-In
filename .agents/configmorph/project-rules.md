# ConfigMorph Project Rules

## Precedence

1. User instruction
2. Root `AGENTS.md`
3. This file
4. Task-specific specification
5. Installed skill instructions
6. Generic model defaults

ConfigMorph architecture and safety always override a conflicting skill. Reject remote fonts despite generic UI advice. Reject performance changes that remove CP checks. Reject adjacent-version assumptions despite generic framework or vendor advice.

Do not put secrets or API keys in repository files. Keep runtime local-only. Do not start Q28 without explicit instruction.
