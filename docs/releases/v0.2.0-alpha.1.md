# ConfigMorph v0.2.0-alpha.1

## Supported candidate scope

- Local FortiGate and Cisco ASA import, detection, normalization, mapping, review, validation, export.
- PAN-OS 11.1 `LOCAL_FIREWALL` candidate generation for supported addresses, groups, services, security policies, and static routes.
- Separate security-rule ordering intent. The artifact is not auto-executed.

## Review-only

- Every NAT subtype. No NAT candidate commands are generated.
- PAN-OS 12.1 target paths lacking verified evidence.
- Panorama and advanced vendor semantics.

## Known limitations

- Application-level validation only. No live device validation. No automatic deployment.
- Local workspace files contain sensitive plaintext. Candidate configuration requires engineer review.
- No PAN-OS 12.1 or Panorama candidate support. No automatic NAT generation.
- Alpha release; no production-readiness or vendor-certification claim.

## Local and offline behavior

Configuration parsing, analysis, migration, review, validation, and export run locally. No telemetry, CDN, runtime external API, or cloud upload is used.

## Documentation provenance

Generated entities retain capability and official documentation reference IDs. Release profiles use version-aware Cisco ASA 9.20/9.22/9.24, FortiOS 7.4/7.6, and PAN-OS 11.1 references.
