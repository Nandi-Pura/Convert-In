# ConfigMorph 0.1.0-alpha.1

Initial alpha release of the local-first firewall configuration analysis, visualization, and migration workbench.

## Highlights

- Cisco ASA, FortiGate, and PAN-OS XML parsing into normalized firewall IR
- dependency visualization and configuration/impact analysis
- ASA → PAN-OS candidate set-command generation
- semantic review, validation, traceability, and guarded review package export
- fully local runtime with no telemetry, cloud API, or external AI API

## Safety

Generated configurations require engineer review and isolated device/lab validation. This alpha does not provide live deployment and is not production-ready. Review the limitations in `README.md` and `docs/migration.md`.

Recommended tag after CI passes: `v0.1.0-alpha.1`.
